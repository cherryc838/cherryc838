# CHERRYC838 V2 — Appliances Store

Professional front-end e-commerce demo focused on home appliances.

## Demo catalog
12 sample products with varied placeholder/demo prices:
- Air fryers
- Blenders
- Microwaves
- Coffee makers
- Kettles
- Toasters
- Cordless and robot vacuums
- Steam irons
- Fans
- Dehumidifiers
- Ice makers

> Prices in this prototype are fictional demo prices and should be replaced with actual selling prices before launch.

## Features
- Green + yellow CHERRYC838 branding
- Responsive design
- Product search
- Category filtering
- Product ratings UI
- Sale / new / trending badges
- Interactive demo cart counter
- Deals section
- Newsletter
- Mobile-ready layout

## Next production phase
Connect a backend/database, real inventory, product photos, cart persistence, checkout, payments, shipping, taxes, customer accounts and admin tools.
